# Pressure Players

An interactive, evidence-led dashboard for the SupeRR Selector S2 Round 1 pressure-player analysis.

## Run locally

Open `index.html` directly, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Data and interpretation

`data.json` and `data.js` are generated by `python scripts/build_data.py` from the audited Phase 3 outputs in the parent data pack. They contain the final ten batters and ten bowlers with selected H1 ratings, 80% intervals, and player evidence. The script needs the parent `p3/results` directory; the deployed dashboard uses `data.js` so it also works when opened directly as a file.

Ratings display win probability added per pressure ball, multiplied by 1,000. The H1 rating borrows heavily from overall player quality because no distinct pressure component was detected. The pressure and normal rates in the player card are observed E1 comparison rates, not the H1 rating. Full definitions, eligibility, prospective validation, and caveats are in `report.pdf`.

Source data covers 786 completed IPL and men's T20I matches from 2022 through the 2026 IPL. No live feeds are used.
